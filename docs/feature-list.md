# DTR 피처리스트

릴리스 개발용 스펙 문서(Notion) 기준.

---

## 1. 전투 코어

- 피해 계산 공식 (기본/지속/고정)
- 치명타 판정 (1.5배 고정)
- 속도 기반 턴 순서 (동률 규칙 포함)
- 턴 구조 (시작/행동/종료 파이프라인)
- 적 AI (가중치 랜덤 + 고정 루프)
- 적 타겟 선택 (단일/광역/상태이상)
- 전투 승패 판정 / 런 종료

## 2. 상태이상 시스템

- 6종 상태이상 (출혈/화상/둔화/약화/파쇄/기절)
- 중첩/갱신 규칙 (출혈·화상 중첩, 나머지 갱신만)
- 효과 적중/저항 공식
- 보스 면역 처리

## 3. 장비 시스템

- 장비 강화 (+1~+3 등급별 비용)
- 장비 효과 적용 (주옵션/부옵션/고유효과)
- 장착/교체/인벤토리 제한 (6칸)

## 4. 유물 시스템

- 6종 유물 효과 + 페널티
- 유물 인벤토리 제한 (4칸)
- 유물 발동 조건 처리

## 5. 보상 시스템

- 전투별 보상 풀 (일반/엘리트/유니크/보스)
- 보물 노드 확정 보상
- 보상 결과가 비어 있지 않음 검증

## 6. 이벤트 시스템

- 4종 이벤트 분기 처리
- 확률 기반 성공/실패 판정
- 숨겨진 선택지 조건/노출
- 이벤트 전투 발생 처리

## 7. 맵 / 노드 시스템

- 1막 3층 노드 구조
- 노드 타입별 분포 랜덤 생성
- 노드 선택 → 진입 → 결과 반영 → 이동 파이프라인
- 전역 출현 규칙 (보물/상점/모닥불/유니크/이벤트)

## 8. 상점 시스템

- 장비/유물/물약 풀 노출
- 구매 + 골드 소비
- 리필 규칙

## 9. 모닥불 시스템

- 휴식 (HP 35% 회복)
- 능력치 투자 (1스텟 +1, 25골드)

## 10. 인벤토리 시스템

- 물약 최대 5개 (동종 중첩)
- 초과 시 폐기 다이얼로그

## 11. 데이터 테이블

- 8개 테이블 (Character/Skill/Enemy/Relic/Equipment/Node/Event/Reward)

## 12. UI / 연출

- 전투 HUD (HP/MP/턴순서/상태이상)
- 맵 UI (노드 타입/경로 구분)
- 이벤트 UI (선택지/결과 표시)
- 상점/모닥불/보상 결과 화면
- 피드백 (공격/피격/치명타/상태이상/승패)
- 사운드 구분

## 13. 콘텐츠 구현

- 일반 적 6종 + 엘리트 3종 + 유니크 2종 + 보스 1종
- 캐릭터 스킬 12개 (4+4+4)
- 이벤트 4종
- 유물 6종 + 장비 12종 + 물약 4종
